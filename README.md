# ETDİOSB Demo

Eskişehir Tarıma Dayalı İhtisas Organize Sanayi Bölgesi için hazırlanmış statik tanıtım ve yatırımcı ön talep demosu.

## Yayın

Site `main` dalına yapılan her gönderimde GitHub Actions ile GitHub Pages'a yayımlanır.

## Demo sınırları

- Giriş kontrolü tarayıcı tarafında çalışır; kurumsal kimlik doğrulamanın yerini tutmaz.
- Ön talep formu gerçek bir veritabanına bilgi kaydetmez veya göndermez.
- Canlı kullanım için güvenli bir sunucu, veritabanı, yetkilendirme ve KVKK süreçleri eklenmelidir.
